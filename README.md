# Meridian

Meridian is a hybrid AI–NWP weather forecasting platform for India that blends multiple numerical and AI-based models into reliable, explainable forecasts. It provides location-based 7-day predictions, model comparison, confidence insights, weather risk alerts, and an interactive visualization dashboard.

## Key Features

- **Hybrid Forecasting**: Blends numerical weather prediction (NWP) models with machine learning models for superior accuracy.
- **Location-Based 7-Day Predictions**: High-resolution forecasting tailored for Indian regions.
- **Model Comparison & Confidence Insights**: Transparent metrics comparing forecast deviations and confidence levels.
- **Weather Risk Alerts**: Real-time warnings for extreme weather events, monsoons, and storms.
- **Interactive Dashboard**: Modern, responsive analytics dashboard built with React and Tailwind CSS.

## Getting Started

### Prerequisites
- Node.js (v18+)
- pnpm / npm

### Installation & Run

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm dev
```
